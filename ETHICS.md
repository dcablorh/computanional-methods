# Ethics statement

- **Human subjects:** none. No people were recruited, surveyed or observed.
- **Personal data:** none collected or stored. The repository contains no addresses, keys or user data.
- **Third-party code:** the demo contracts were written for this project. No deployed contract was copied, and no live network was queried.
- **Dual use:** the detector and its localization output could in principle help an attacker find a flaw before its owner does. The tool is a pre-deployment check and was tested only on the six demo contracts. The vulnerable demo contracts are minimal, public-pattern examples (the classic reentrancy and timestamp patterns) and do not contain a working exploit.
- **Responsible disclosure:** no vulnerabilities in real systems were found or reported.
- **Secrets:** no API keys, passwords or tokens are in the repository or in the submitted notebooks.
- **Restricted data:** none. The planned public datasets are not in the repository and need their own access check before use.
