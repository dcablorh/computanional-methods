# AI-use disclosure

This project was carried out with an AI coding assistant (Claude Code, Anthropic) working in the author's repository, following the author's instructions. The author is responsible for the scope, the decisions and the final submission.

## What the assistant wrote

These files were written by the assistant during the sessions in which this work was done, using its file-editing and command tools:

- Code changes: the training-label fixes in `data_loader.py`; the legacy-AST operator fix and the compound-assignment fix in `slicing/slicer.py` and `model/gnn.py`; the refactor of `trainer.py` into `fit_model`.
- New evaluation code: `evaluate.py` (leave-one-contract-out evaluation and baselines) and `evaluate_external.py` (external test).
- The four notebooks in `notebooks/`, generated by a script and then executed.
- The documentation: `README.md`, `DATA_CARD.md`, `MODEL_CARD.md`, `ETHICS.md`, `FAILURE_LOG.md`, `REPRODUCIBILITY_CHECKLIST.md`, `LITERATURE_MATRIX.md`, and this file.
- The six external test contracts in `test_contracts/`.
- The manuscript and slides HTML drafts, and the PDF renderings of them.
- The web searches used to check references.

## What the author did

- Chose the research question, the evaluation design (leave-one-contract-out as the main protocol, with an external test), and the baselines.
- Directed each step, including the decision to make the arithmetic fix.
- Reviewed the results and asked for checks on them.

## How results were checked

- Every number in the manuscript and slides was taken from files in `results/` and `results/logs/`.
- Retraining reproduces the committed `model.pth` byte for byte (see `REPRODUCIBILITY_CHECKLIST.md`).
- References were checked against publisher or arXiv pages before use (see `LITERATURE_MATRIX.md`).

## Limits of this disclosure

- The external test contracts were written by the assistant, not by an independent party. The external result was also used to find one defect (`FAILURE_LOG.md`, F12), so it is not independent.
- No dataset other than the six demo contracts and the six external contracts in this repository was downloaded or used.
